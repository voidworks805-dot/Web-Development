# Pomodoro Timer

A clean, responsive Pomodoro Timer web application built with semantic HTML and CSS.

## Features
- **Tab Navigation**: Mode switcher for *Pomodoro*, *Short Break*, and *Long Break*.
- **Responsive Layout**: Designed for desktop, tablet, and mobile screens.
- **Dynamic Mobile Breakpoints**: Automatically stacks buttons and switches to compact single-word labels (`Focus`, `Short`, `Long`) on small screens (`≤ 480px`).
- **Interactive UI**: Hover effects and custom styling.

## Project Structure
- `index.html` — Semantic HTML structure
- `style.css` — Modern responsive styles and media queries
- `script.js` — JavaScript timer logic

## How to Run
Simply open `index.html` in any web browser.
